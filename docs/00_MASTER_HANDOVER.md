# DENTALSOFT

## MASTER HANDOVER DOCUMENT

Version: 1.0

# PROJECT IDENTITY

**Project Name:** DentalSoft

**Category:** Professional Dental Practice Management Software

**Target Market:** Dental Clinics, Private Practices, Dental Centers

**Primary Country:** Algeria

**Currency:** Algerian Dinar (DA)

**Languages:** French (Default), Arabic, English

# PROJECT VISION

DentalSoft is **not** an admin dashboard or a CRUD demo. It is intended
to become a production-grade commercial dental practice management
system comparable to Dentrix, OpenDental, CareStack, Curve Dental and
Denticon.

# PRIMARY GOAL

-   Improve dentists' daily workflow
-   Reduce clicks
-   Deliver a premium user experience
-   Solve real clinical workflows
