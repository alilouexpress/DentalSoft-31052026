# PROJECT OVERVIEW

## Purpose

DentalSoft is a commercial dental practice management system focused on
Algerian clinics.

## User Roles

-   Receptionist
-   Dentist
-   Assistant
-   Clinic Manager
-   Administrator

## Clinical Workflow

Patient Registration → Appointment → Examination → Odontogram → Imaging
→ Diagnosis → Treatment Plan → Prescription → Billing → Follow-up

## Functional Modules

Patients, Appointments, Medical History, Odontogram, Imaging, Treatment
Plan, Prescriptions, Payments, Documents, Inventory, Reports.
